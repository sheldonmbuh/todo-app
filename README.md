# Task Tracker

A to-do app that actually remembers. Tasks are saved in the browser with localStorage, so they survive a refresh. Add, complete, delete, and filter tasks.

## What this project shows

- Creating and updating DOM elements from data, safely (text is set with textContent, never injected as HTML)
- Persisting state with localStorage and re-rendering from a single source of truth
- Filtering a list by state: all, open, done

## Run it

Open `index.html` in any browser. Add a task, refresh the page, and it is still there.

## Why it exists

This is the project where front-end basics turn into a real app: state, storage, and an interface that stays in sync with the data. It is also personal. My whole system runs on checklists, so this one had to work properly.
